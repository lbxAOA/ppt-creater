## 选择原则

- 每个候选仅为**独立模板族**；不会把其页面拼接进其他来源的 deck。
- 第 2 轮优先解决“行业语境和专有页面系统”缺口，而不是重复补通用封面、目录或图文页。
- Slidesgo 免费模板页常要求保留归因页；在用途、发行形式和授权条款完成逐模板审查前，一律维持 `manual_external_review_required`。
- 进入生产前仍需：合法下载 → PPTX 结构/可编辑性检查 → 全页联系表 → 人工风格/用途确认 → `slot_*` 映射 → 填充验证 → PowerPoint 动画播放验收。

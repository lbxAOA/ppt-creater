# Public template asset manifest

This directory contains reusable PPTX binaries that are identified as
user-owned local production sources or derived native masters. It intentionally
does not include third-party network intake, network masters, validation copies,
or generated output decks.

The software in this repository is MIT-licensed. Template binaries are separate
assets and are not automatically covered by the software license. Before
redistributing a specific PPTX, verify the rights for that asset.

## Included asset groups

- `template-library/local-production-sources/` — user-owned source templates.
- `production-library/` — user-owned production masters.
- `production-template-library/` — selected native production masters.
- `complete-production-library/` — selected complete native masters.

Generated validation copies remain local and are excluded from version control.
